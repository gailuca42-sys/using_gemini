# using_gemini
A collection of creative and technical projects built with Gemini APIs, showcasing how AI can enhance interactivity, analysis, and design. This repository is a playground for experimenting with the power and versatility of Gemini.

Running the Application
In general, to run this type of app, follow these steps:


Open your terminal (Command Prompt, PowerShell, or Terminal) in the project folder.


Install dependencies:
npm install



Start the development server:
npm run dev



The terminal will display a local URL (usually http://localhost:5173).
Open this link in your web browser to interact with the app.

You have the description of each project in the metadata.json file.
